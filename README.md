# ⚖ Fernandes & Souza Advogados Associados
![image](https://github.com/user-attachments/assets/0c12d4b9-4ba1-4bfe-92c8-2dc61a0b66e8)

Este projeto é uma landing page desenvolvida para um escritório de advocacia dedicado a fornecer serviços jurídicos personalizados. A plataforma apresenta informações sobre as áreas de atuação, equipe de advogados e canais de contato, com foco na comunicação clara e acessível.

## Funcionalidades
- **Design Responsivo**: Compatível com diferentes dispositivos.
- **Perfis da Equipe**: Informações sobre os advogados.
- **Áreas de Atuação**: Descrição detalhada dos serviços jurídicos.
- **Formulário de Contato**: Canal para comunicação direta, com envio de e-mail direto na página.

## Tecnologias Utilizadas
- **Framework**: Next.js.
- **Hospedagem**: Vercel.
- **Estilização**: Tailwind.
- **Animação**: Framer Motion.
